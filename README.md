# Overview
This project conveys the comparison between Myanmar export and import values between 2019 (pre-pandemic) and 2022 (post-pandemic and regime change in 2021) in US billion dollars. Since February 1, 2021, Myanmar military seized power from the democratic civilian government, leading to a series of mass protests and instability across the country. Both pandemic and political instability have pushed Myanmar economy to the blink.

The trading sector has been severely impacted because of these two double crises. The aim of the project is to highlight shift in trade values between partner countries for the years, 2019 and 2022. As the trading sector is vast, only top six partner countries based on trade values are analyzed in the report.

The dataset used in this project is referenced from World Integrated Trade Solution (WITS) website.
